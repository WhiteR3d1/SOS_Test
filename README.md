# ฝึกทำข้อสอบ Operating Systems

เว็บฝึกทำข้อสอบปรนัย **110 ข้อต่อครั้ง** สร้างจากสไลด์วิชา Operating Systems (`SOS.pdf`, 59 หน้า, 8 บท)
ทุกครั้งที่กดเริ่มทำ ระบบจะสุ่มชุดคำถาม ลำดับข้อ ลำดับตัวเลือก และตัวเลขในโจทย์คำนวณขึ้นมาใหม่

## วิธีใช้

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งหรือต่ออินเทอร์เน็ต

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `css/style.css` | สไตล์ รองรับธีมสว่าง/มืด และจอมือถือ |
| `js/concepts.js` | คลังนิยามแนวคิด 163 รายการ — สร้างคำถามได้ 2 ทิศทาง (ศัพท์→นิยาม, นิยาม→ศัพท์) |
| `js/bank.js` | กลุ่มคำถาม "ข้อใดใช่/ไม่ใช่" 46 กลุ่ม + ข้อสอบเชิงวิเคราะห์ที่เขียนมือ 107 ข้อ |
| `js/generators.js` | ตัวสร้างโจทย์คำนวณแบบสุ่ม 27 แบบ (ตัวเลขเปลี่ยนทุกครั้ง) |
| `js/app.js` | เครื่องสร้างข้อสอบ ระบบตรวจคะแนน และส่วนติดต่อผู้ใช้ |

## การสุ่มข้อสอบ

ข้อสอบแต่ละชุดดึงจาก 4 แหล่ง รวมเป็นคลังข้อ 389 ข้อที่ไม่ซ้ำกัน บวกกับตัวสร้างโจทย์ที่ให้ตัวเลขใหม่ทุกครั้ง

ระบบจำว่าข้อไหนเพิ่งออกไป แล้วหยิบข้อที่ยังไม่เคยออกขึ้นมาก่อน ผลคือ
**ทำติดกัน 2 ครั้งจะไม่เจอข้อซ้ำกันเลยแม้แต่ข้อเดียว** และคลังจะวนครบรอบทุก ๆ ประมาณ 3–4 ครั้ง
ส่วนโจทย์คำนวณจะได้ตัวเลขชุดใหม่เสมอแม้จะเป็นโจทย์แบบเดิม

## ฟีเจอร์

- **2 โหมด** — โหมดสอบจริง (ตรวจตอนท้าย) และโหมดฝึกฝน (เฉลยทันทีทีละข้อ)
- **เฉลยพร้อมคำอธิบายทุกข้อ** โจทย์คำนวณแสดงวิธีทำทีละขั้น เช่น การไล่ตารางแทนที่หน้าทุกบรรทัด
- ตารางข้อ 110 ช่อง กดข้ามไปข้อไหนก็ได้ ทำเครื่องหมายข้อที่ไม่มั่นใจได้
- สรุปคะแนนรายบท และกรองดูเฉพาะข้อที่ผิด/ถูก/ไม่ได้ตอบ
- จับเวลา เก็บประวัติคะแนน 20 ครั้งล่าสุด และทำค้างไว้แล้วกลับมาทำต่อได้
- คีย์ลัด `1`–`4` เลือกคำตอบ, `←` `→` เปลี่ยนข้อ, `F` ทำเครื่องหมาย
- ธีมสว่าง/มืด · ข้อมูลทั้งหมดเก็บใน localStorage ของเบราว์เซอร์เท่านั้น
